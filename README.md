## <img src="https://api.iconify.design/mdi/lightbulb-on-outline.svg?color=%23FFB300" width="24" style="vertical-align:middle"/> What Is It?

**AI HomeWork Helper** is a study companion built for students who get stuck on an exercise and just want a clear explanation — fast. No typing out the whole problem, no digging through textbooks.

A student simply **snaps a photo** of their homework — a math equation, a science question, an essay prompt, anything — or **speaks the question out loud**, and the app sends it to a **large language model** to generate a clear, understandable solution, explained step by step, in the student's own language.

The app is built with **Flutter** and connects to **Firebase** for its backend needs, with the AI layer designed to route requests — text, image, or audio — across **multiple AI providers**, so students always get a reliable answer, in any language.

## <img src="https://api.iconify.design/mdi/sitemap.svg?color=%23FF7043" width="24" style="vertical-align:middle"/> Architecture — Snap, Send, Solve

The core flow of the app is built around one simple loop: **capture → analyze → explain**.

```
┌────────────────────┐     ┌────────────────┐     ┌───────────────────────┐     ┌──────────────────┐
│  📷 Photo · 🎤 Audio │ ──▶ │  ☁️ Firebase    │ ──▶ │  🤖 AI Model Router     │ ──▶ │  📖 Step-by-Step  │
│  or typed question   │     │  (upload/auth) │     │  ChatGPT · Gemini · Grok│     │  Solution, any language │
└────────────────────┘     └────────────────┘     └───────────────────────┘     └──────────────────┘
```

1. **Flutter UI** — Camera capture, gallery import, voice recording, and a clean results screen.
2. **Firebase** — Handles authentication, storage, and cloud configuration.
3. **AI Model Router** — Forwards the homework input (image, audio, or text) to the selected AI provider (ChatGPT, Gemini, or Grok) and formats the returned solution.
4. **Localization Layer** — Detects the student's language and responds in that same language automatically.
